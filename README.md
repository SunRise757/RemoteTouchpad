# Remote Touchpad
Simple application designed to control your computer with a phone over LAN
## Features
- User Authentication/Authorisation
- Touchpad
- Scrollbar
- Keyboard
## Technologies Used
### Backend
- **Go (Golang)**: High-performance backend server
- **Gorilla WebSocket**: Real-time bidirectional communication
- **Standard Library HTTP**: Built-in HTTP server with custom routing
- **bcrypt**: Password hashing for secure authentication
### Frontend
- **Qt Widgets 6.7.3**: Cross-platform GUI framework
- **WebAssembly**: Browser-based deployment via Emscripten
- **C++**: Modern C++ standards for performance and features
### Communication
- **WebSocket Protocol**: Real-time, low-latency data transfer
- **HTTP/REST**: Standard API endpoints for authentication and operations
- **JSON**: Lightweight data interchange format
